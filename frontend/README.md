# Community Intranet Frontend

React-19-PWA mit Vite, TypeScript, Tailwind CSS 4 und TanStack Query. Lokale
Start- und Testbefehle stehen in der README im Repository-Root.

Der Phase-8-Assistent streamt einen persistenten Chat über die Backend-API,
liest Projekte und Aufgaben über begrenzte Werkzeuge und bereitet Änderungen
zur sichtbaren Bestätigung vor. Projekte und Aufgaben öffnen interaktive
Detailansichten; Aufgaben unterstützen Subtasks, Kommentare und Screenshots.
WebMCP registriert dieselben fachlichen Zugriffe optional für kompatible
Browser-Agenten.
Details stehen in
[`docs/ai-assistant-webmcp.md`](../docs/ai-assistant-webmcp.md).
