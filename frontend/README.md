# Community Intranet Frontend

React-19-PWA mit Vite, TypeScript, Tailwind CSS 4 und TanStack Query. Lokale
Start- und Testbefehle stehen in der README im Repository-Root.

Der Phase-7-Assistent erzeugt über die Backend-API bestätigungspflichtige
Projektentwürfe und registriert optional dieselben Aktionen als WebMCP-Tools.
Details stehen in
[`docs/ai-assistant-webmcp.md`](../docs/ai-assistant-webmcp.md).
